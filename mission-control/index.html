Mission Control

See the agents working alongside your Codex chat.

You direct the work in one conversation. When Codex delegates to specialists, Mission Control shows who is working on what, their state, and when they last updated.

Made by Amit Ayre

Install the skill

Codex on macOS
$ npx skills@latest add amitdialpad/amitdialpad.github.io --skill mission-control -g -a codex

Run in a terminal, then invoke the skill in Codex to open your own dashboard.

Invoke with

After installation
> $mission-control

Ask Codex to open your local dashboard. It uses your own session records.

What it does

Opens a private dashboard on your Mac, reads local Codex agent records, and refreshes the roster as work changes. Each row shows the agent, assignment, short explanation, state, and update time.

When to use it

Ask Codex to delegate a few pieces of work. Then invoke $mission-control to see each agent and its current assignment in one place.

WHY WE MADE IT

A clear view of delegated work.

In a long chat

Who has the UI review? Did QA finish? Where is the latest update?

In Mission Control

One live table shows the agent, assignment, short explanation, state, and update time.
