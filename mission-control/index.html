Mission Control

A Codex skill that shows the agents working in your chat. See their assignments, current state, and latest update in one place.

Install the skill

Codex on macOS
$ npx skills@latest add amitdialpad/amitdialpad.github.io --skill mission-control -g -a codex

Run in a terminal, then invoke the skill in Codex to open your own dashboard.

Invoke with

After installation
> $mission-control

Ask Codex to open your dashboard. It uses your own session records.
